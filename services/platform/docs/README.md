# Platform documentation

Use [Self-hosted setup](self-hosted-setup.md) to run Platform and msg against
local D1 databases. The guide uses the current Wrangler configuration and
provisioning scripts.

The guide is local setup and operator preparation. It does not claim live
Google or GitHub provider access, a production deployment, or completion of
T11, T12, or T15.

The Platform slice reports and the [ticket proposal](PLATFORM_MVP_TICKETS.md)
record the setup's status and remaining acceptance boundaries.
