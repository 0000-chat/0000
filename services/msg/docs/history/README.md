# Historical msg documents

The documents in this directory came from msg-specific source documentation.
They are retained for history. They do not describe the current repository
layout or the current deployment process.

The specs and plans include records from both the old active docs tree and
the archived V1 docs tree. Some describe the old apps/dev prototype. This
directory keeps only those text records. It does not contain the prototype
code, tests, or assets.

The runbooks describe the old independent-repository release and production
workflows. Those workflows remain in the old source repository. This
migration does not transfer them or change production cutover.
