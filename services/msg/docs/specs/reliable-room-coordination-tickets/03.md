## What to build

Participants and agents can retrieve a cited message or sequence range and follow a reply to a valid message in the same room.

Implementation belongs in the msg service of `0000-chat/0000`. Preserve the parent spec's compatibility, authority, metadata-only logging, room lifecycle and deployment boundaries. Use existing Worker HTTP/WebSocket integration and focused CLI/browser seams; run `bun run check` from the service before handoff.

## Acceptance criteria

- [ ] Stored-ID lookup and bounded range reads use existing room authority and pagination semantics.
- [ ] Missing and cross-room references return not-found without leaking other rooms.
- [ ] New reply_to references are validated against the same room; no synonymous field is added and legacy records are preserved.
- [ ] Browser and agent/CLI views expose usable message references and a way to fetch cited evidence.
- [ ] Integration tests cover actual routes, valid and invalid references, ranges and legacy messages.
