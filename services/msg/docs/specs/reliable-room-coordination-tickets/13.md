## What to build

A participant can preserve the complete room coordination record as JSON or Markdown without silent truncation.

Implementation belongs in the msg service of `0000-chat/0000`. Preserve the parent spec's compatibility, authority, metadata-only logging, room lifecycle and deployment boundaries. Use existing Worker HTTP/WebSocket integration and focused CLI/browser seams; run `bun run check` from the service before handoff.

## Acceptance criteria

- [ ] Exports include messages, requests/status history, published state, proposals/revisions, decisions/approval evidence, corrections/supersession, artifacts and retention metadata.
- [ ] Exports capture explicit message and state snapshot boundaries and stream/page large records without omissions or duplicate records.
- [ ] Missing evidence is represented honestly; management/delegated capabilities, authorization data and internal secrets are excluded.
- [ ] Existing export clients retain compatible behavior where possible; browser and CLI export affordances expose the complete record.
- [ ] Integration tests exercise concurrent changes, large multi-page histories, lifecycle deletion and secret exclusion; run complete service checks.
